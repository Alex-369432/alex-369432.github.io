## Перенос домена pitomnik-siba-inu.ru — в процессе

Домен уже принадлежит пользователю, сейчас на нём старый одностраничный сайт на Tilda (реальный трафик/обратные ссылки — миграция низкорисковая, т.к. в старом sitemap был только один URL).

DNS управляется через **Тильду** (не reg.ru/nic.ru напрямую). В Тильде нашёлся полноценный раздел DNS-записей: `tilda.ru/domains` → домен → **DNS-записи**, с кнопкой «Добавить DNS-запись» — можно менять A-записи напрямую, Cloudflare не понадобился.

**Что нужно:** заменить текущую A-запись (`176.57.64.119` — IP старого сайта на Тильде) на 4 записи GitHub Pages:
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```
CNAME для `www.pitomnik-siba-inu.ru` (сейчас указывает на `pitomnik-siba-inu.ru`) — не трогать.

Файл `CNAME` с содержимым `pitomnik-siba-inu.ru` уже добавлен в репозиторий (закоммичен и запушен) — на стороне GitHub всё готово.

Пользователь не смог сам поменять A-запись через личный кабинет Тильды — написал в поддержку Тильды с точным текстом обращения (просил заменить A-запись на эти 4 IP). **Ждём ответа/действий поддержки или пользователя.**

**Как проверить в новой сессии, сработал ли перенос:**
```powershell
Resolve-DnsName -Name pitomnik-siba-inu.ru -Type A
```
Если один из адресов выше — перенос сработал, можно проверить `https://pitomnik-siba-inu.ru/` и включить «Enforce HTTPS» в Settings → Pages репозитория. Если всё ещё `176.57.64.119` — ещё не сделано, уточнить у пользователя статус переписки с поддержкой Тильды.
